## 🎯 Objetivo
Desenvolver um sistema em Python capaz de realizar a gestão de acervo de uma biblioteca, incluindo cadastro, listagem, busca inteligente por título e geração de relatórios visuais de quantidade por gênero literário.

---

## ⚙️ Funcionalidades
- [x] **Classe Livro:** Estruturação orientada a objetos (`titulo`, `autor`, `genero`, `qtd_disponivel`).
- [x] **Cadastro:** Inclusão das instâncias na lista global `Livro.livros`.
- [x] **Listagem:** Visualização formatada do catálogo.
- [x] **Busca:** Pesquisa case-insensitive por títulos.
- [x] **Gráfico Matplotlib:** Agrupamento e exibição visual do estoque por gênero.
